# financial-transaction-clustering-classification
This project analyzes 2,512 financial transaction records using unsupervised learning to identify natural behavior clusters. By applying K-Means and the Elbow Method, it reveals distinct transaction patterns, detects potential fraud, and provides insights to improve financial security and anomaly monitoring.

## Project Overview
The dataset provides a comprehensive view of transaction behaviors and financial activity patterns. Each record contains information such as transaction amounts, timestamps, demographic details, and usage patterns.

Through data preprocessing, normalization, and clustering analysis, the project uncovers underlying structures in user behavior, enabling better fraud detection and risk assessment.

## Key Techniques
1. Unsupervised Learning (K-Means Clustering)
2. Elbow Method for optimal cluster selection
3. Feature Normalization and Scaling
4. Visualization of Cluster Distribution
